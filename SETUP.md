# One-Time Bootstrap Setup

These are UI settings, not files, so a repo admin needs to click through them
once. Should take about 10 minutes total.

## 1. Branch Protection on `main`

Settings → Branches → Add branch protection rule → branch name pattern `main`

Turn on:
- [ ] **Require status checks to pass before merging**
  - Select the `validate` check (from `validate.yml`) once it's run at least once
- [ ] **Require branches to be up to date before merging**
  - This is what enforces sequential merges automatically
- [ ] Leave **"Require a pull request before merging"** on, but do **not**
      check "Require approvals" — this keeps review optional per your team's
      decision, while still forcing changes through a PR (not a direct push).

## 2. Add Teammates

Settings → Collaborators → add the other 2-3 devs with **Write** access.

## 3. Add Repo Secrets (for the Actions to authenticate to the dev org)

Settings → Secrets and variables → Actions → New repository secret

- [ ] `SF_DEV_AUTH_URL` — the org's SFDX auth URL, generated by running
  `sf org display --verbose --json` against an already-authenticated
  connection to the dev org and copying the `sfdxAuthUrl` field. This lets
  the GitHub Action log in non-interactively via `sf org login sfdx-url`.

> Also replace `AUTHORING_BUNDLE_NAME` in `validate.yml` and `deploy.yml`
> with the actual authoring bundle API name (the folder name under
> `force-app/main/default/aiAuthoringBundles/`).

## 4. GitHub ↔ Chat Integration (optional but recommended)

Install the GitHub app for your team's chat tool (Slack/Teams) and subscribe
the channel to this repo:

```
/github subscribe afnanmoh15/AgentforceVersionControl
```

This posts merges to `main` automatically, replacing manual "I merged" pings.

## 5. First PR to Confirm the Setup Works

- [ ] Create a throwaway branch, make a trivial change, open a PR
- [ ] Confirm `validate.yml` runs and shows as a required check
- [ ] Confirm merge is blocked until the check passes
- [ ] Merge it, delete the branch
- [ ] Confirm the chat integration posted the merge (if configured)

Once this checklist is done, the loop in [README.md](./README.md) is live —
send that to the team.
